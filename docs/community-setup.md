```
### Describe the bug

### Expected behavior

### ClawForge version
### Debug logs (if any)
```

**Feature Request:**
```

### Use case
```

## 4. Community Guidelines

1. **Be respectful** — everyone's here to learn and share
2. **Show, don't just tell** — share your YAML scripts and output videos
3. **Help others** — if you solved a problem, share the solution
4. **No spam** — promotional content goes in #showcase only
5. **English preferred** — so the global community can participate
